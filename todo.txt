Blog feature plan (Thinking Machines style)

Decisions
- URL structure: /blog/<slug>
- Authoring: MDX
- Fields: title, description, date, slug, hero image, content
- RSS: not needed (keep SEO + OG + sitemap)
- Visual: match reference closely

MDX schema (frontmatter)
- title: string
- description: string (maps to summary today)
- date: ISO string (maps to publishedAt today)
- slug: string (derived from filename by default)
- hero: string (relative path to image)

Plugin stack (Next MDX, RSC-compatible)
- TOC: derive from headings (we already add ids via `app/components/mdx.tsx`)
- Footnotes: remark-gfm (supports footnotes) + custom renderer for margin notes
- Slugs: use existing slugify in mdx.tsx for anchors
- Code: sugar-high (already in place)
- Optional: rehype-autolink-headings if we remove custom heading wrapper later

Index layout spec
- Page title and subtitle matching Connectionism styles
- List posts with: date (left), title (link), subtitle/author line (optional), right-aligned chevron
- Generous vertical rhythm; hover underline on title
- Pagination optional (start with all posts)

Post layout spec
- 3-column grid: left sticky TOC, center prose, right margin for footnotes
- On <lg screens: hide TOC; footnotes render centered beneath relevant content
- Active section highlighting in TOC based on heading intersection
- Hero image (optional) full-width above article; date below title
